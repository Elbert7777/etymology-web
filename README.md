# 📚 词根词缀法学习工具

一个简洁优雅的在线学习工具，帮助你通过词根词缀法系统记忆英语单词。

## ✨ 特性

- 🎨 **配色标记系统**：前缀（蓝色）、后缀（红色）、词根（绿色）一目了然
- 📝 **拆词公式**：清晰展示单词的构成逻辑，理解记忆更深刻
- 🃏 **交互闪卡**：内置20张闪卡，支持翻面、乱序、键盘快捷键
- 📱 **完全响应式**：手机、平板、电脑都能完美显示
- 🚀 **零依赖**：纯 HTML/CSS/JS，打开即用，无需安装

## 📖 内容涵盖

### 12大前缀（决定词义）
- 方向类：外/出、内/进、前、回
- 关系类：聚集、分散、相互
- 程度类：上/超过、下/不足
- 特殊类：转移、强调、否定

### 3大后缀（决定词性）
- 动词后缀：-ate, -ize, -ify, -ish
- 形容词后缀：-ent, -ful, -ous, -al, -ive, -ible, -able, -ant
- 名词后缀：-ion, -tion, -ation, -ness, -ity, -ment, -ence, -ance, -ism

### 常用词根（核心义）
- radi/radic（射线/根）
- pose（放）
- port（搬运）
- vis/vid（看）
- dict（说）

## 🎯 使用方法

### 在线访问
直接访问 GitHub Pages：[https://Elbert7777.github.io/etymology-web/](https://Elbert7777.github.io/etymology-web/)

### 本地使用
1. 克隆或下载本仓库
2. 直接用浏览器打开 `index.html`
3. 无需任何配置，立即开始学习

### 闪卡练习
- 点击卡片或"翻面"按钮查看答案
- 使用"上一题"/"下一题"切换
- 点击"乱序"打乱顺序，增加记忆难度
- 键盘快捷键：
  - `Space/Enter`：翻面
  - `←`：上一题
  - `→`：下一题

## 📝 学习建议

1. **先理解系统**：掌握"前缀-词根-后缀"的基本公式
2. **成对记忆**：对立概念一起记（如：外/内、上/下）
3. **联想记忆**：通过词根联想记忆同族单词
4. **间隔重复**：定期使用闪卡复习，对抗遗忘曲线
5. **实际应用**：遇到新单词时尝试拆解分析

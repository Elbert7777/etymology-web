一、总览：单词 = 词根 + 词缀

词缀是"形变外壳"，词根是"核心意思"。掌握这个公式，单词记忆效率提升10倍。

前缀决定词义
如：un-表否定
后缀决定词性
如：-tion表名词
词根决定核心义
如：pose=放
💡 记忆口诀：前缀管"什么意思"，后缀管"什么词性"，词根管"核心是什么"。

二、12 大前缀（决定词义）

按语义成对/成组记忆，效果最好。对立概念一起记，印象更深刻。

  1. 外 / 出：e / ex / ef → export 出口 | exit 出口
  2. 内 / 进：in / im → inject 注射 | import 进口
    ⚠️ im- 同时是"否定"前缀（见第12类），二者来源不同，需要根据上下文判断。
  3. 前：
    • 动态·向前：pro → progress 进步 | promote 促进
    • 静态·在前/预先：pre → preview 预习 | predict 预测
  4. 回 / 重新 / 再次：re → return 返回 | review 复习 | repeat 重复
  5. 聚集（一起 / 共同）：co / com / con / col → connect 连接 | cooperate 合作
  6. 分散 / 分开：di / dis / dif → divorce 离婚 | divide 分开 | differ 不同
  7. 上 / 超过：super / over / sur → superman 超人 | overcome 克服 | surface 表面
  8. 下 / 不足：under / de / sub / sup → subway 地铁 | degrade 降级 | submarine 潜水艇
  9. 转移 / 转变：trans → transfer 转移 | transform 转变 | translate 翻译
  10. 相互之间：inter → internet 互联网 | international 国际的 | interact 互动
  11. a + 双写辅音 = 强调（无实义）：如 arise 出现, awake 醒来
    a- 在此起加强语气作用，非介词意义。
  12. 否定前缀：un / im / in / dis / ab / ap / il
    • unhappy 不快乐 | impossible 不可能 | invisible 看不见的 | disorder 混乱
    ⚠️ 与第2类 im- 同形不同源：这里表"不"，那里表"进入"。

三、3 大后缀（决定词性）

后缀决定单词的词性，是语法功能的关键。

1. 动词后缀

-ate / -ize / -ify / -ish
activate 激活 | realize 实现 | simplify 简化 | publish 出版

2. 形容词后缀

-ent / -ful / -ous / -al / -ive / -ible / -able / -ant
different 不同的 | careful 小心的 | famous 著名的 | natural 自然的
active 积极的 | possible 可能的 | able 能够的 | important 重要的

3. 名词后缀

-ion / -tion / -ation / -ness / -ity / -ality / -ment / -ence / -ance / -ism
action 行动 | nation 国家 | education 教育 | happiness 幸福
ability 能力 | movement 运动 | difference 差异 | importance 重要性

四、常用词根（核心义）

词根是单词的灵魂，掌握高频词根可以举一反三。

1. radi = 射线 / 辐射

radius → n. 半径：想象从圆心射出的"辐条"
radiate → v. 放射；散发：像射线一样向外发散
radiation → n. 辐射：向外发出的射线或能量

2. radic = 根（root）

radical → adj. 根本的 / 彻底的
eradicate → v. 根除：把根拔出来
⚠️ 易混提示：radi- 是"射线、辐射"，radic- 是"根"。两者拼写相近，但不是同一个词根。

3. pose = 放 / 放置（put）

expose = ex(向外) + pose(放) → 往外放 → v. 暴露；揭露
compose = com(一起) + pose(放) → 放在一起 → v. 组成；创作
propose = pro(向前) + pose(放) → 把想法放到前面 → v. 提议；求婚
oppose = op(对面/反对) + pose(放) → 把观点放对面 → v. 反对
💡 op- 是 ob- 在 p 前的变体，单词实际拼作 oppose
dispose = dis(分开) + pose(放) → 放到别处 → v. 处理；丢弃
impose = im(进入) + pose(放) → 放到别人身上 → v. 强加

4. port = 搬运 / 携带（carry）

export = ex(外) + port(搬运) → 运出去 → v./n. 出口；输出
import = im(进入) + port(搬运) → 运进来 → v./n. 进口；输入
transport = trans(转移) + port(搬运) → 搬运转移 → v./n. 运输；交通
portable = port(携带) + able(能) → adj. 便携式的；手提的

5. vis / vid = 看（see）

visible = vis(看) + ible(能) → adj. 可见的
invisible = in(不) + visible → adj. 看不见的
video = vid(看) + eo → n. 视频
television = tele(远) + vis(看) + ion → n. 电视

6. dict = 说 / 断言（say）

predict = pre(预先) + dict(说) → v. 预测；预言
dictionary = dict(说) + ionary → n. 字典：关于词语"说法"的书
contradict = contra(相反) + dict(说) → v. 反驳；矛盾

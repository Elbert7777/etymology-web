前缀 = 词义 后缀 = 词性 词根 = 核心义

一、总览：单词 = 词根 + 词缀

词缀是"形变外壳"，词根是"核心意思"。

前缀决定词义
后缀决定词性
词根决定核心义
记忆口诀：前缀管"什么意思"，后缀管"什么词性"，词根管"核心是什么"。

二、12 大前缀（决定词义）

按语义成对 / 成组记忆，效果最好。

  1. 外 / 出：e / ex / ef → export 出口
  2. 内 / 进：in / im → inject 注射
    ⚠️ im- 同时是"否定"来源（见第 12 类），二者来源不同，别混。
  3. 前：
    动态·向前：pro → progress 进步
    静态·在前 / 预先：pre → preview 预习
  4. 回 / 重新 / 再次：re → return 返回 / review 复习
  5. 聚集（一起 / 共同）：co / com / con / col → connect 连接
  6. 分散 / 分开：di / dis / dif → divorce 离婚 / divide 分开
  7. 上 / 超过：super / over / sur → superman 超人
  8. 下 / 不足：under / de / sub / sup → subway 地铁（sub = 下）
  9. 转移 / 转变：trans → transfer 转移
  10. 相互之间：inter → internet 互联网
  11. a + 双写辅音 = 强调（无实义）：如 arise, awake（a- 在此起加强语气作用，非介词）
  12. 否定前缀：un / im / in / dis / ab / ap / il → unhappy, impossible, invisible, disorder
    与第 2 类 im- 同形不同源：这里表"不"，那里表"进入"。

三、3 大后缀（决定词性）

动词后缀：ate / ize / ify / ish → activate, realize, simplify, publish
形容词后缀：ent / ful / ous / al / ive / ible / able / ant → different, careful, famous, natural, active, possible, able, important
名词后缀：ion / tion / ation / ness / ity / ality / ment / ence / ance / ism
⚠️ 原文写作 "lon"，应为 ion（如 action, nation）。

四、词根（核心义）

1. radi = 根（root）

radical adj. 根本的 / 彻底的
eradicate v. 根除

2. pose = 放（put）

expose：ex(向外)+pose(放) → 往外放 → v. 暴露 / 揭露
compose：com(一起)+pose(放) → 放一起 → v. 组成 / 创作
propose：pro(向前)+pose(放) → 把想法放前面 → v. 提议 / 求婚
oppose：op(对面/反对)+pose(放) → 把观点放对面 → v. 反对
⚠️ 说明：op- 是 ob- 的变体（遇 p 同化为 op），但单词实际拼作 oppose，不要写成 obpose；原笔记写 "op" 是对的。
dispose：dis(分开)+pose(放) → 放别处 → v. 处理 / 丢弃
impose：im(进入)+pose(放) → 放到别人身上 → v. 强加

五、勘误与说明（加工记录）

• 名词后缀原文 "lon" → 修正为 ion。
• "op(对面)" → 原写法正确，无需改。op- 是 ob- 变体（遇 p 同化），但单词仍拼作 oppose，不可改成 obpose。
• im- 在第 2 类（内 / 进）与第 12 类（否定）同形，已分别注明来源不同。
• 原文词根编号 "1. … 2：pose" 不连续，已顺延为规范编号。
• 新增少量高频例词（preview, connect, divide, superman, subway, activate 等）仅为辅助记忆，未改动原博主核心内容。

单词 = 词根 + 词缀

词缀是"形变外壳"，词根是"核心意思"。掌握这个公式，单词记忆效率提升10倍。

前缀决定词义
如：un-表否定
后缀决定词性
如：-tion表名词
词根决定核心义
如：pose=放
💡 记忆口诀：前缀管"什么意思"，后缀管"什么词性"，词根管"核心是什么"。
🧭 怎么用这个页面：左边侧栏点任意词根直达（手机点底部"词根"标签），找具体词直接用顶部搜索框。

配色规则

全文统一配色，看到颜色就知道是词缀还是词根：

蓝色 = 前缀   决定词义方向（ex- 向外 / re- 重新 / in- 进入…）
红色 = 后缀   决定词性（-tion 名词 / -able 形容词 / -ize 动词…）
绿色 = 词根   核心含义（pose 放 / port 搬运 / dict 说…）

12 大前缀

决定词义 · 按语义成对/成组记忆，对立概念一起记，印象更深刻。

  1. 外 / 出：e / ex / ef → export 出口 | exit 出口
  2. 内 / 进：in / im → inject 注射 | import 进口
    ⚠️ im- 同时是"否定"前缀（见第12类），二者来源不同，需根据上下文判断。
  3. 前：
    • 动态·向前：pro → progress 进步 | promote 促进
    • 静态·在前/预先：pre → preview 预习 | predict 预测
  4. 回 / 重新 / 再次：re → return 返回 | review 复习 | repeat 重复
  5. 聚集（一起 / 共同）：co / com / con / col → connect 连接 | cooperate 合作
  6. 分散 / 分开：di / dis / dif → divorce 离婚 | divide 分开 | differ 不同
  7. 上 / 超过：super / over / sur → superman 超人 | overcome 克服 | surface 表面
  8. 下 / 不足：under / de / sub / sup → subway 地铁 | degrade 降级 | submarine 潜水艇
  9. 转移 / 转变：trans → transfer 转移 | transform 转变 | translate 翻译
  10. 相互之间：inter → internet 互联网 | international 国际的 | interact 互动
  11. a + 双写辅音 = 强调（无实义）：如 arise 出现, awake 醒来
    a- 在此起加强语气作用，非介词意义。
  12. 否定前缀：un / im / in / dis / ab / ap / il
    • unhappy 不快乐 | impossible 不可能 | invisible 看不见的 | disorder 混乱
    ⚠️ 与第2类 im- 同形不同源：这里表"不"，那里表"进入"。

3 大后缀

决定词性 · 后缀是判断单词"是名词还是动词"的关键。

1. 动词后缀

-ate / -ize / -ify / -ish
activate 激活 | realize 实现 | simplify 简化 | publish 出版

2. 形容词后缀

-ent / -ful / -ous / -al / -ive / -ible / -able / -ant
different 不同的 | careful 小心的 | famous 著名的 | natural 自然的
active 积极的 | possible 可能的 | able 能够的 | important 重要的

3. 名词后缀

-ion / -tion / -ation / -ness / -ity / -ality / -ment / -ence / -ance / -ism
action 行动 | nation 国家 | education 教育 | happiness 幸福
ability 能力 | movement 运动 | difference 差异 | importance 重要性
